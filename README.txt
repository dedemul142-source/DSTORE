DSTORE - PAKET PWA LENGKAP

Isi paket:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

CARA UPLOAD KE GITHUB PAGES:
1. Ekstrak ZIP.
2. Upload seluruh isi folder ke root repository GitHub Pages.
3. Jangan mengubah nama file.
4. Pastikan GitHub Pages aktif pada branch/folder yang benar.
5. Buka situs melalui HTTPS.
6. Di Chrome Android, buka menu browser lalu pilih Install app / Tambahkan ke layar utama.
7. Jika opsi belum muncul, tunggu deployment selesai lalu muat ulang halaman.

CATATAN:
- Instalasi PWA memerlukan HTTPS (atau localhost) dan dukungan browser.
- Prompt instalasi otomatis tidak tersedia di semua browser.
- Data toko lokal tersimpan pada browser/perangkat yang digunakan.
- Perubahan admin tidak otomatis tersinkron ke perangkat pelanggan tanpa backend.
- Katalog tertanam berasal dari DEMULL_STORE_BACKUP (5).json terbaru.
